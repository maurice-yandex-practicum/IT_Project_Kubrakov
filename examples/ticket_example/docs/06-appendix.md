# Приложение А. Состав документов

Газетный анализ (§2.3.5): каждое поле документа — атрибут ER (знак «?» — условие поиска), и для каждого поля указано, куда его записывает или откуда берёт функция (Q — обращение, которое пишет поле или ищет по нему; A — ответ хранилища, из которого берётся поле).
