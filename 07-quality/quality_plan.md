# Служебный порядок сопровождения методики испытаний

Основной артефакт — quality.md. В нём определены критерии КР-01–КР-12, проверки П-01–П-28, контрольные наборы и условия вывода. requirements.md содержит ссылки каждого требования на проверки. ERD.drawio.xml содержит модель требований/критериев/проверок/выполнений; BPMN.drawio.xml — четыре действующих представления. Ссылки на устаревшие уточняющие листы не используются.

При изменении правила сначала изменить его основное определение, затем данные, потоки, задачи/исполнителя, архитектурный механизм и контрольный эталон. Проверить, что новое значение не появилось только в одном документе. Для самостоятельного запроса нужны собственный результат и проверка; внутреннее чтение не заменяет этот запрос.

Тесты здесь подготовлены к реализации; статическая сверка документации не считается выполненным API-прогоном. Контрольные примеры необходимы для объяснения метода, полный комплект пошаговых кейсов/актов не требуется. П-28 оценивает реальный тестовый API шлюза; подмена не закрывает его. П-24–П-26 требуют фактического участия представителей ролей.

Изображения PNG сохраняются в прежней редакции по условию этой работы. Проверка текущих схем выполняется по XML; актуальность PNG не объявляется подтверждённой. В сдаваемый артефакт служебные условия работы агента не переносятся.
