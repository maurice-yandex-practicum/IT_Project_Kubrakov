# ПРИЛОЖЕНИЕ. Перечень сокращений, терминов и источников

## ПЕРЕЧЕНЬ СОКРАЩЕНИЙ И ОБОЗНАЧЕНИЙ

В настоящем отчёте применяют следующие сокращения и обозначения:

- АС — автоматизированная система;
- БД — база данных;
- ВУ — водительское удостоверение;
- ГК РФ — Гражданский кодекс Российской Федерации;
- ДТП — дорожно-транспортное происшествие;
- ПДД — Правила дорожного движения;
- ПМИ — программа и методика испытаний;
- ТС — транспортное средство;
- API — Application Programming Interface (программный интерфейс приложения);
- BPMN — Business Process Model and Notation (нотация моделирования бизнес-процессов);
- DFD — Data Flow Diagram (диаграмма потоков данных);
- ER — Entity-Relationship (модель «сущность — связь»);
- JSON — JavaScript Object Notation (формат обмена данными);
- JWT — JSON Web Token (токен доступа);
- REST — Representational State Transfer (архитектурный стиль программного интерфейса);
- SMTP — Simple Mail Transfer Protocol (протокол передачи электронной почты);
- VIN — Vehicle Identification Number (идентификационный номер транспортного средства).

## ТЕРМИНЫ И ОПРЕДЕЛЕНИЯ

В настоящем отчёте применяют следующие термины с соответствующими определениями:

**Аренда транспортного средства без экипажа** — по договору аренды арендодатель предоставляет арендатору транспортное средство за плату во временное владение и пользование без оказания услуг по управлению им и его технической эксплуатации (ГК РФ, гл. 34).

**Арендатор (потребитель)** — физическое лицо, заключившее договор аренды ТС без экипажа и управляющее им.

**Бронирование** — резерв конкретного ТС за пользователем на ограниченный срок до начала аренды. В границы проекта не входит.

**Выполнение проверки** — зафиксированный факт выполнения проверки в определённых условиях с указанием версии объекта, наблюдений, итога и свидетельства.

**Каршеринг** — вид пользования автомобилем, когда одна из сторон не является его собственником; вариант краткосрочной аренды автомобиля у профильных компаний для внутригородских и коротких поездок.

**Критерий оценки** — проверяемое свойство с правилом сравнения, применимыми условиями и, где необходимо, единицей измерения и порогом.

**Покрытие требований** — сведения о том, для каких требований подготовлена проверка. Покрытие не означает выполнения проверки.

**Проверка** — сценарий получения свидетельства с входными данными, исходными условиями, ожидаемым результатом и методом наблюдения.

**Результат использования** — сведения о том, достиг ли участник своей задачи и как он оценил взаимодействие с системой.

**Свидетельство** — наблюдаемый результат проверки: ответ программного интерфейса, состояние данных, подтверждённое сообщение, журнал, временные отметки или результат работы участника.

**Тариф** — ценовая модель аренды, задающая единицу времени и стоимость за единицу времени. Дополнительные виды платы в рамках проекта не моделируются.

**Телематический модуль** — программно-аппаратный комплекс в составе ТС, обеспечивающий удалённое открытие и закрытие автомобиля, передачу координат, пробега, уровня топлива, уровня заряда и статуса. Запуск двигателя и диагностические коды в границы проекта не входят.

**Требование** — проверяемое утверждение о системе с идентификатором, основанием, условием применения и ожидаемым результатом.

**Транспортное средство (ТС)** — легковой автомобиль: автомобиль, предназначенный для перевозки пассажиров и багажа, разрешённая максимальная масса которого не превышает 3500 кг, а число сидячих мест помимо сиденья водителя — не более восьми. Объектом аренды в АС каршеринга может быть только легковой автомобиль: грузовые автомобили, автобусы, мототранспортные средства и иные виды транспортных средств в парк не включаются (общее понятие — ПДД РФ, п. 1.2; критерии категории B — Федеральный закон «О безопасности дорожного движения», ст. 25; ограничение парка только легковыми автомобилями задано условиями проекта).
