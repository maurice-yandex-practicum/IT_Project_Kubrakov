## 2. Глоссарий

| Термин | Определение | Источник |
|---|---|---|
| **Каршеринг** | Вид пользования автомобилем, когда одна из сторон не является его собственником; вариант аренды автомобиля у профильных компаний (чаще всего для внутригородских и/или коротких поездок) или частных лиц | Памятка «Защита прав потребителей при оказании услуг каршеринга» |
| **Аренда транспортного средства без экипажа** | По договору аренды арендодатель предоставляет арендатору транспортное средство за плату во временное владение и пользование без оказания услуг по управлению им и его технической эксплуатации | ГК РФ, гл. 34; памятка |
| **Арендодатель (исполнитель)** | Организация, предоставляющая услуги каршеринга; обязана владеть ТС на законных основаниях, зарегистрировать их, подтвердить соответствие технического состояния и заключить договоры ОСАГО | Памятка |
| **Арендатор (потребитель)** | Физическое лицо, заключившее договор аренды ТС без экипажа и управляющее им | Памятка |
| **Телематический модуль** | Программно-аппаратный комплекс в составе ТС, обеспечивающий удалённое открытие/закрытие, запуск двигателя, передачу координат, пробега, уровня топлива и диагностических кодов | Составлено по материалам отрасли [ДОПУЩЕНИЕ: конкретный стандарт/поставщик не зафиксирован] |
| **Бронирование** | Резерв конкретного ТС за пользователем на ограниченный срок до начала аренды | Составлено по материалам отрасли |
| **Тариф** | Ценовая модель аренды: поминутная, почасовая или посуточная ставка, при необходимости — доплата за километраж | Памятка; материалы операторов |
| **Единая биометрическая система (ЕБС)** | Государственная система удалённой идентификации граждан по биометрическим данным; планируется к применению для верификации пользователей каршеринга | News.ru |
