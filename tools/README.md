# Инструменты работы с диаграммами draw.io

`build_tech_diagram.py` собирает `06-tech_project/technical_solution.drawio.xml`: размещение и обмены, устройство rental, устройство state. Запуск: `py -3.14 tools/build_tech_diagram.py`. Необязательный параметр `--preview-dir ПАПКА` создаёт изображения для просмотра через Pillow; исходник draw.io собирается стандартной библиотекой. Подписи, координаты и связи задаются в этом скрипте.

`py -3.14 tools/check_tech_project.py` проверяет основания проверок методики (назначение, правила, функции и разделы технического проекта), коды BPMN в техническом проекте, идентификаторы и геометрию новой схемы. При проверке маршрутов учитываются точки входа/выхода блоков и только массив points; смещение подписи offset в маршрут не включается.

`drawio.py` — инспектор и минимальный редактор .drawio-файлов (Python 3, без сторонних пакетов). Правки выполняются на уровне строк, остальная разметка сохраняется как есть.

## Команды

| Команда | Что делает |
|---|---|
| `python3 tools/drawio.py pages FILE` | список листов с числом вершин и рёбер |
| `python3 tools/drawio.py cells FILE "Имя листа"` | вершины листа: id, подпись, геометрия |
| `python3 tools/drawio.py edges FILE "Имя листа"` | рёбра: `source -> target : подпись` |
| `python3 tools/drawio.py find FILE "Имя листа" TEXT` | поиск подписи по вершинам и рёбрам |
| `python3 tools/drawio.py stat FILE "Имя листа"` | степень каждой вершины (для проверки баланса DFD) |
| `python3 tools/drawio.py dot FILE "Имя листа" [OUT.dot]` | выгрузка листа в Graphviz DOT |
| `python3 tools/drawio.py check FILE` | проверка XML-валидности файла |
| `python3 tools/drawio.py set-label FILE "Имя листа" SRC TGT TEXT` | заменить подпись ребра |
| `python3 tools/drawio.py set-cell FILE "Имя листа" ID TEXT` | заменить подпись вершины (например, имени связи ER) |
| `python3 tools/drawio.py add-child FILE "Имя листа" PARENT CHILD "Подпись"` | добавить вершину-потомок под родителем и ребро |

## Замечания

- Имена листов передаются так, как в атрибуте `name` `<diagram>` (например, `"DFD level 1"`).
- Перед правкой сохраните файл в Git — `set-label` и `add-child` перезаписывают его.
- `stat` считает входящие/исходящие рёбра; для проверки баланса контекстной диаграммы и DFD уровня 1 сравнивайте степени внешних сущностей.

## `beautify.py` — автоформатирование диаграмм

Делает диаграммы draw.io более читаемыми: раздвигает пересекающиеся блоки, перекладывает рёбра ортогонально с обходом препятствий (A*), разводит параллельные рёбра и гарантирует белый фон подписей рёбер. Не меняет подписи и стили заливки. Только стандартная библиотека.

| Команда | Что делает |
|---|---|
| `python3 tools/beautify.py check ФАЙЛ [ЛИСТ...]` | диагностика: пересечения блоков и пересечения рёбер с блоками, без изменений |
| `python3 tools/beautify.py fix ФАЙЛ [ЛИСТ...]` | применить правки (перезаписывает файл) |

Опции `fix`: `--no-layout` (не раздвигать блоки), `--margin N` (отступ рёбер от блоков, по умолчанию 12), `--grid N` (шаг сетки маршрутизации, по умолчанию 10), `--dry-run` (показать, что изменится, без записи).

Перед запуском `fix` сохраните файл в Git — он перезаписывается на месте.
